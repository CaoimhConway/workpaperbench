# Release table and measurement notes

This is an explicitly synthetic dated-release case. P1 and P2 are adjacent observation periods for Ethereum USDC with the same authored population and metric definition. Each release row gives the total in whole token units. No price, exchange rate, or USD valuation input is supplied.

A release is eligible for an as-of result when its publication date is on or before the requested cutoff. Use the latest eligible publication date separately for each period. Preliminary publications are eligible when they fall on or before the cutoff.

The `releases` table preserves publication date and release kind. `transfer_units` is a token-unit amount, not USD. The USD request cannot be converted from these records.
